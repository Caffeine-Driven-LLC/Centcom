One place where people and their coding agents work together.

Centcom is terminal-first multiplayer for your own Claude Code and Codex. Run agents, share a session, see who is working on what, and stay in charge of what gets approved. Your credentials never leave the tools that own them.

Get Centcom How it works

Two ways to work together

Pick one when you start a session. Both use the same session, the same queue and the same approvals.

Available now

Command post

One computer, the host, runs the agents. Everyone else sends requests to a shared queue and watches. The host approves what the agent may run. Good for pairing, reviews and live help.

Early

Branch mode

Everyone runs their own agents on their own copy of the project. The session shows who is working on what, marks files an agent has open, and warns an agent before it touches a file someone else is editing. Work can be handed from one person to another.

Across computers, not just across the desk

On the same network, sessions are found and joined with a pairing code: no account, no server, no cost. Further apart, hosted sessions go through an encrypted relay. Everything is encrypted on your computer first with keys the relay never has, so teammates in another city see the same session you do. What the relay can and cannot see.

Use it where you already work

Available now

Command line

The full terminal app: chat with the agent, approve tools, share and join sessions. Needs Node 22 or newer.

In development

Desktop app

A window around the same screens: running sessions in a sidebar, a session panel with people, shared notes and changed files, and search on Ctrl or Cmd+K. Installers are planned; today it runs from source.

Early

Hosted web app

The same screens in a browser, for joining a session as a guest and managing your workspace and plan. The public address is not decided yet.

Built to be trusted

  • Your own agents. Centcom drives the Claude Code and Codex you already have. It never reads, stores or sends their credentials.
  • You approve. The owner of an agent approves its tools, on their own computer.
  • End-to-end encrypted. The relay carries sessions it cannot read.
  • Free where it is local. Working alone or on your own network is always free.
  • No tracking. This site has no analytics and no cookies; the app's telemetry is off unless you turn it on.
