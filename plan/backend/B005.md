## Goal
Every log line is structured JSON carrying a request id, with a redaction layer that makes it impossible to log tokens, keys, ciphertext, message bodies, paths or branch names by accident.

## In scope
- pino-based `createLogger(cfg)` returning a child-capable logger with fields service, env, version, request_id, session_id, user_id (ids only).
- Redaction engine: key-name deny list (authorization, cookie, set-cookie, token, refresh_token, access_token, secret, password, api_key, ct, sig, text, p, body, path, branch, cwd, device_code, user_code, code_verifier, code), plus value patterns (`cen_(live|test)_`, JWT-shaped strings, Bearer values).
- Request-id handling for Fastify (plugin apps/api/src/plugins/request-context.ts): accept a valid `req_` ULID from `X-Request-Id`, else generate one; echo `X-Request-Id`; store in AsyncLocalStorage so deep code can log without passing it.
- Access-log hook: one line per request with method, route template (not raw URL), status, duration_ms, bytes, never headers or bodies.
- Metrics hook points: a small `Metrics` interface (counter/histogram) with a no-op default; the exposure endpoint belongs to a later status lane.

## Out of scope
- Error serialisation to problem+json (B006).
- OpenTelemetry tracing/export pipeline (later observability lane).
- Audit events (B036); logs are not the audit trail.

## Interfaces (the only surface other lanes may use)
- `createLogger(opts:{level:string; service:string; version:string; destination?: NodeJS.WritableStream}): Logger`.
- `redact(value: unknown): unknown` (pure, returns a deep copy with secrets replaced by `[redacted]`).
- `getRequestContext(): {requestId: string; userId?: string; sessionId?: string} | undefined`; `runWithContext(ctx, fn)`.
- `requestContextPlugin: FastifyPluginAsync` registering hooks; response header `X-Request-Id`.
- `interface Metrics { counter(name, labels?): {inc(n?)}; histogram(name, buckets): {observe(v, labels?)} }`.

## Acceptance criteria
1. A request without `X-Request-Id` gets a response header matching `^req_[0-9A-HJKMNP-TV-Z]{26}$`; a request with a valid one gets the same value back; an invalid one (e.g. `abc`) is replaced, not echoed.
2. Logging `{authorization:'Bearer abc', nested:{refresh_token:'x'}}` outputs `[redacted]` for both and keeps non-secret keys.
3. A string value `cen_live_` followed by 32 base62 chars, or a three-part base64url JWT, is replaced by `[redacted]` wherever it appears in a log object value.
4. Each request produces exactly one access-log line containing `request_id`, `route` (e.g. `/v1/sessions/:id`), `status`, `duration_ms`; the line never contains query string values.
5. Log lines are single-line valid JSON (parse 1 000 generated lines with JSON.parse, zero failures).
6. The context survives `await`, timers and nested async calls: `getRequestContext()` returns the same id inside a setTimeout started in a handler.
7. Redaction of a 1 MB object completes in under 50 ms and never mutates its input.

## Tests required
- redact.test.ts: key list, value patterns, cycles, depth cap 8, no input mutation.
- request-context.test.ts: header echo, invalid id replacement, ALS propagation.
- access-log.test.ts: single line per request, route template, no query values.
- fuzz.test.ts: random nested objects never throw from redact().

## Guardrails (MUST / MUST NOT)
- MUST NOT log request or response bodies, `p`/`ct` of frames, file paths, branch names, tokens, keys, or full URLs with query strings.
- MUST apply redaction at the logger serializer level so call sites cannot bypass it; MUST NOT offer an unredacted raw logger.
- MUST use the route template for logs and metric labels, never the raw path (prevents id/PII cardinality and leaks).
- MUST cap logged string values at 2 000 chars (truncate with an ellipsis).

## Failure modes
- Logger destination write fails -> drop the line, increment a `log_dropped_total` counter, never throw into request handling.
- Redaction hits a cyclic or exotic object -> replace the subtree with `[unserialisable]`.
- X-Request-Id header repeated -> use the first, ignore the rest.
