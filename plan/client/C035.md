## Goal
A multiline prompt input with history, paste handling, inline slash-command suggestions and correct Unicode editing, matching DESIGN §10.1.1.

## In scope
- Bordered prompt box (`border.default`, `border.strong` when focused, `signal` while an agent runs, `status.danger` + message below on error): minimum 3 rows, grows to 12 rows then scrolls; gutter `▸` coloured `accent.primary` idle, `signal` running, `status.warning` awaiting approval.
- Editing buffer (`TextBuffer`) with grapheme-aware cursor (Intl.Segmenter), selection-free in v1; keys: `⏎` send, `shift+⏎` newline (with fallbacks `ctrl+j` and trailing `\` + `⏎` for terminals that cannot report shift+enter), `ctrl+a/ctrl+e` line start/end, `alt+b/alt+f` word move, `ctrl+w` delete word, `ctrl+u` delete to line start, `ctrl+d` delete forward (only when non-empty), arrows, home/end.
- History: `up`/`down` at first/last line walk previous prompts, persisted to `<data>/history.jsonl` (max 1,000 entries, consecutive duplicates collapsed, per-project filter, entries over 8 KiB are not stored); `ctrl+r` opens a reverse search line.
- Bracketed paste: pastes of more than 10 lines or 2,000 chars collapse to a chip `[Pasted text #1 +42 lines]` that expands on send; hard cap 256 KiB of pasted text per prompt.
- Slash commands: `SlashCommandRegistry` and an inline suggestion list (max 8 rows, fuzzy match, matched chars `signal` bold) opened by typing `/` at position 0; `tab` completes, `⏎` runs; built-ins registered here: `/clear` and `/exit`. Other lanes register theirs (`/model`, `/resume`, `/rewind`, `/cost`, settings commands).
- Placeholder text in `text.muted`: `What should we build?` (solo) or `Message the fleet…` (team) selected by prop; disabled state with a visible reason line.

## Out of scope
- The full command palette overlay (lane C041, which reuses this registry).
- Permission mode cycling on `shift+tab` and its state (lanes C015 and C045).
- Routing a submitted message to an agent, or to a queue submit in a command post (session/queue client lanes); this lane emits `onSubmit` only.
- `@file` mention completion and image attachments (not in v1; see notes).

## Acceptance criteria
1. Typing `héllo 👩‍💻` then backspace twice removes the emoji cluster as one unit and then `o`; cursor columns are correct for wide characters (snapshot of cursor position).
2. The box is 3 rows when empty, grows by one row per added line up to 12 rows, then scrolls with the cursor line always visible; snapshot at 15 lines.
3. `⏎` calls `onSubmit` once with the full text; an empty or whitespace-only buffer does not submit; text over 65,536 characters is rejected with the inline error `Message is too long (max 65,536 characters).` and is not sent (matches the `message.user` text limit).
4. Pasting 50 lines via bracketed paste inserts one chip `[Pasted text #1 +49 lines]`; on submit `onSubmit` receives the expanded text; pasting 300 KiB inserts only the first 256 KiB and shows a warning line.
5. History: after submitting `a`, `b`, `b`, pressing up twice yields `b` then `a` (duplicate collapsed); history file never exceeds 1,000 lines; entries from another project are not offered.
6. Typing `/mo` shows suggestions including a registered `/model`, `tab` completes to `/model `, `esc` closes the list without clearing the text; list height <= 8 rows.
7. While `status='running'` the border uses the `signal` token and the gutter glyph colour changes; under `NO_COLOR` the running state is also shown by the text `running` in the box's top border.
8. `ctrl+j` inserts a newline in a terminal that sends plain `\r` for shift+enter; a line ending in `\` followed by `⏎` inserts a newline instead of sending.

## Guardrails (MUST / MUST NOT)
- MUST NOT send or store anything while the text contains unsanitised control sequences from a paste; strip ESC sequences from pasted text before insertion.
- MUST treat pasted text as data only: a paste never triggers a slash command or a submit even if it contains newlines or starts with `/`.
- MUST NOT write history entries that begin with a secret-looking prefix handled by the redaction helper from lane C005 (e.g. API key patterns); skip storing rather than store redacted text.
- MUST NOT register `ctrl+k` (command palette), `ctrl+t`, `ctrl+b` or `shift+tab`; those belong to other lanes (DESIGN §22.2).
- MUST NOT block on history file I/O; reads happen once at mount, writes are fire-and-forget with error swallowing plus a debug log.
- Disabled state MUST show the reason (e.g. viewers cannot send messages per CT-RBAC) instead of silently ignoring input.

## Failure modes
- History file unwritable -> keep history in memory for the process, log once at warn.
- Terminal does not support bracketed paste -> pasted multi-line text arrives as keystrokes; detect >= 5 characters within one tick containing newlines and treat as a paste to avoid accidental submit.
- Slash command throws -> show an inline error `/<name> failed. <short message>.` and keep the buffer.
