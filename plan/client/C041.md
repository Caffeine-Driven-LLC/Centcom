## Goal
A fast command palette overlay (ctrl+k) that searches commands, files, sessions and skills with fuzzy matching, grouped results and keyboard-only operation, per DESIGN §10.1.10.

## In scope
- Overlay box centred, 60 columns wide (or `cols-4` when the terminal is narrower), results grouped `Commands · Files · Sessions · Skills`, max 8 visible rows with scroll indicator, footer hints `↑↓ move · ⏎ run · esc close`.
- Fuzzy matcher `fuzzyScore(query, text)` (subsequence with bonuses for consecutive, word-start and path-separator matches; case-insensitive, smart-case) returning score and matched indices; matched characters rendered `signal` + bold.
- Provider interface `PaletteProvider` with built-in providers: Commands (from the lane C035 `SlashCommandRegistry`, shown with a leading `/`), Files (injected file index, `git ls-files` or fs walk, cap 20,000 entries), Sessions (lane C026 `list`), Skills (lane C020 loader).
- Empty query shows up to 5 recent commands; typing queries all providers in parallel with a 30 ms input debounce and a 100 ms per-provider soft timeout (late results append without moving the selection).
- Opening: action `palette.open` (`ctrl+k`) and inline `/` handling reused by the prompt suggestion list; running a result calls the provider's `run`; focus is trapped in the overlay and restored to the prompt on close.
- No-results copy from DESIGN §13.3: `Nothing matches "<query>". Try fewer words or check the spelling.`

## Out of scope
- Defining the commands themselves (each owning lane registers its own).
- Keybinding remapping and help (lane C045).
- Indexing file contents or semantic search.
- Mascot in the palette (DESIGN limits the mascot to waits, first-run, empty states, outcomes).

## Build against (no counterpart needed)

## Interfaces (the only surface other lanes may use)
- `<CommandPalette providers: PaletteProvider[]; onClose: () => void />`
- `interface PaletteProvider { id: string; group: 'Commands'|'Files'|'Sessions'|'Skills'; search(q: string, signal: AbortSignal): Promise<PaletteItem[]>; recent?(): PaletteItem[] }`; `type PaletteItem = {id: string; label: string; detail?: string; run(): void | Promise<void>}`
- `fuzzyScore(query: string, text: string): {score: number; indices: number[]} | null`
- `createFileIndex(deps: {cwd: string; limit?: number}): { search(q: string, signal: AbortSignal): Promise<PaletteItem[]> }`
- Action ids: `palette.open` (`ctrl+k`), `palette.close` (`esc`), `palette.next` (`down`), `palette.prev` (`up`), `palette.run` (`enter`).

## Acceptance criteria
1. The overlay is exactly 60 columns wide at 80x24 and 120x40 and `cols-4` at 50 columns; at most 8 result rows are shown, with a `▾ 12 more` row when more exist.
2. `fuzzyScore('cmp','command palette')` matches and outranks `fuzzyScore('cmp','scope compare')`; a non-subsequence returns null; matched index highlighting is correct for 20 table cases.
3. Typing 3 characters triggers one provider query (debounce 30 ms), and typing a 4th aborts the previous query via `AbortSignal`.
4. A provider that takes 2 s does not delay the first paint of faster providers (first results visible within 150 ms with fake clock) and its late results do not change the selected row.
5. `↓` at the last row wraps to the first; `⏎` runs the selected item and closes the overlay; `esc` closes and returns focus to the prompt with its text intact.
6. With the Files provider on a repo of 20,000 files, a query returns top 5 in under 50 ms p95 after the first index build; the index build streams and never blocks input for more than 16 ms at a time.
7. No-results state shows the exact copy and no mascot; empty query shows `Recent`-labelled commands.
8. Grouping order is fixed Commands, Files, Sessions, Skills and a group with no matches is omitted.

## Tests required
- palette/fuzzy.test.ts: scoring table and property test (indices ascending, score deterministic).
- palette/providers.test.ts: debounce, abort, soft timeout, late results.
- palette/render.test.ts: snapshots at 80x24, 50x20, 120x40, NO_COLOR.
- palette/keys.test.ts: navigation, wrap, run, close and focus restore.
- palette/file-index.test.ts: 20k-file benchmark guard, ignored files.

## Guardrails (MUST / MUST NOT)
- MUST trap focus while open and restore it on close (DESIGN §16.2).
- MUST NOT execute anything on selection movement; only `⏎` runs, and destructive commands keep their own confirmation.
- MUST sanitise file and session labels with `sanitizeForTerminal` (file names can contain escape sequences).
- MUST NOT include files matched by .gitignore or outside the repo root in the Files group, and MUST NOT follow symlinks out of the root.
- MUST bound the file index at 20,000 entries and say `Showing first 20,000 files` once when truncated.
- Every action must remain reachable by keyboard only; no mouse paths.

## Failure modes
- A provider throws -> omit its group and show a muted row `Skills unavailable` for that group only.
- File index build fails (not a git repo, permission error) -> fall back to a depth-limited (depth 6) walk; if that fails, omit Files silently and log at debug.
- Terminal resized while open -> recompute width and keep the selection.
## Notes
Palette results for Sessions and Skills depend on lanes C026 and C020 interfaces; providers are injected so this lane compiles without them.
