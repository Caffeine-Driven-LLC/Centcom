## Goal
The web app has one place that guarantees WCAG 2.2 AA behaviour (focus, live regions, motion, forced colours, zoom) and one message table system for localisation, so every feature lane gets accessibility and i18n by using shared helpers.

## In scope
- i18n in apps/web/src/i18n/: typed message table (`en.json` as source of truth), `t(key, params)` with ICU-lite plurals, locale detection (`/v1/me` locale, then navigator), lazy-loaded locale chunks, `Intl` formatting helpers for dates, numbers, money; pseudo-locale `en-XA` for testing; message keys for notification titles/bodies (CT-NOTIF-PAYLOAD) and error codes (CT-ERR) live here.
- a11y helpers in apps/web/src/a11y/: `<LiveRegion>` (polite default, assertive for blocking errors), focus management (`useFocusReturn`, `FocusTrap`), skip link, roving tabindex hook, shortcut registry with `?` help overlay and user remapping persisted in localStorage.
- Motion: `useReducedMotion()` reading `prefers-reduced-motion` and a manual setting equal to CENTO_REDUCE_MOTION semantics (`/motion [full|reduced]` parity); forced-colors (`forced-colors: active`) styles; `data-theme="hc"` reserved.
- Text equivalents for agent states: a `stateText(state, params)` table for all 61 names in CT-STATE-MAP (e.g. 'Cento is editing 3 files').
- Lint and test tooling: eslint-plugin-jsx-a11y strict config, a Vitest `expectNoA11yViolations()` helper (axe-core), a lint rule banning raw string literals in JSX text outside tests/stories.
- Docs page `docs`-style README with the manual test checklist of DESIGN.md 16.4.

## Out of scope
- Feature-specific copy (each feature lane adds its keys to its own section file but through this framework).
- TUI accessibility (C049).
- The primitives themselves (C081) and e2e suite (C093).
- Right-to-left layouts (not in v1).

## Interfaces (the only surface other lanes may use)
- export function t(key: MessageKey, params?: Record<string, string|number>): string  // MessageKey is a generated union type from en.json
- export function useLocale(): {locale: string; set(l: string): Promise<void>}
- export function LiveRegion(props: {politeness?: 'polite'|'assertive'; children: ReactNode}): JSX.Element
- export function useReducedMotion(): boolean
- export function registerShortcut(def: {id: string; keys: string; labelKey: MessageKey; scope: string; handler(): void}): Unsubscribe
- export function expectNoA11yViolations(container: HTMLElement, opts?: {impacts?: ('serious'|'critical')[]}): Promise<void>

## Acceptance criteria
1. Missing translation key at build time fails `pnpm --filter @centcom/web i18n:check` (keys used in code must exist in en.json; unused keys warn).
2. Pseudo-locale `en-XA` expands strings by ~30 % and layout tests show no clipped or overflowing text at 320 px.
3. Error codes: every code returned in CT-ERR registry that the web handles maps to a message key; unknown codes map to the HTTP status class text (400/401/403/404/409/429/5xx), test table.
4. All 61 state names have `stateText` entries; unknown states return 'Cento is working'.
5. Skip link is the first tabbable element and moves focus to <main>; focus returns to the trigger after any modal closes (test with 3 modal types).
6. With reduced motion on, `useReducedMotion()` is true and no CSS animation duration > 0 remains on the shell page (computed-style scan).
7. Under `forced-colors: active` (Playwright emulation helper) borders and focus rings remain visible; no information lost.
8. Shortcuts registry detects conflicting key bindings and logs a dev error; every shortcut is remappable and listed in the `?` overlay.
9. Locale chunk for any non-English locale <= 20 KB gzip and loaded lazily; English is inlined in the shell budget (<= 10 KB gzip).

## Guardrails (MUST / MUST NOT)
- MUST NOT put display text on the wire or accept display text from the server; all user-visible text comes from message tables keyed by code (CT-NOTIF-PAYLOAD, `sys.notice`).
- MUST set `<html lang>` from the active locale and update it on change.
- MUST NOT auto-dismiss any content that requires action; toasts with actions persist (DESIGN.md 16.2).
- System messages MUST be plain, short sentences without idioms (jokes only in spinner lines).
- Live regions MUST NOT contain the mascot; blocking errors use assertive, everything else polite.

## Failure modes
- Locale chunk fails to load -> fall back to English with a one-time toast.
- Locale from /v1/me unsupported -> pick closest BCP 47 prefix, else `en`.
- localStorage unavailable -> shortcut remaps last for the session only.
## Notes
v1 ships `en` only plus the pseudo-locale; framework supports adding locales without code changes. Message wording rules come from DESIGN.md section 13 (voice) and 13.5 terminology cheat-sheet.
