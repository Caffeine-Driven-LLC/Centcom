## Goal
A reusable web mascot canvas player renders Cento animations from animations.json for any product state name, with lazy loading, pixel-exact scaling, a cap on simultaneous animations and full reduced-motion and screen-reader behaviour.

## In scope
- React component `<Mascot>` in apps/web/src/mascot/ drawing frames from packages/mascot data on <canvas> with `image-rendering: pixelated`, integer scale (multiples of 2), frame durations per frame `d` ms, DPR-aware.
- State lookup via CT-STATE-MAP (state-map.json): `stateToAnimation(state)`; unknown state falls back to the `thinking` animation.
- Lazy loading: animations.json split by category (`cat`), fetched on first use; decoded once and cached as ImageBitmap/ImageData per frame and colour.
- Global animation scheduler: at most 6 animating canvases at once (DESIGN.md 19.6); extras freeze on frame 0; pause when the tab is hidden or the element is off-screen (IntersectionObserver).
- Behaviour rules: 600 ms minimum dwell, hard cuts between states, one-shot animations play once then return to the actual state, `prompt-received` bridge max 200 ms; five body colours via palmap.
- Static SVG/PNG fallback frame for reduced motion and for no-canvas environments; `aria-hidden="true"` always.

## Out of scope
- Terminal half-block renderer and TUI component (C033, C046).
- Deciding which state to show for an agent (the callers; the mascot never drives state).
- Producing animations or art (assets/mascot build scripts).
- Mascot-free surfaces are enforced by callers via a lint rule shipped here.

## Build against (no counterpart needed)
Local assets/mascot/animations.json and assets/theme/state-map.json via packages/mascot (C009); no network, no backend.

## Deliverables
- `apps/web/src/mascot/`
- `apps/web/test/mascot/`

## Interfaces (the only surface other lanes may use)
- export function Mascot(props: {state: StateName|string; colour?: 'violet'|'red'|'yellow'|'green'|'brown'; size?: 24|36|48|96; label?: string; priority?: 'normal'|'low'}): JSX.Element
- export function stateToAnimation(state: string): {animation: string; known: boolean}
- export function useMascotBudget(): {animating: number; max: 6}
- ESLint rule `centcom/no-mascot-in-sensitive` forbidding <Mascot> inside <PaymentForm>, <ConsentText>, <SecurityWarning>, <ConfirmDestructive>, [aria-live=assertive].

## Acceptance criteria
1. Every one of the 61 state names in contracts/state-map.json resolves to an existing animation name in animations.json (test iterates all keys); unknown state resolves `thinking` with known=false.
2. Rendered canvas dimensions are integer multiples of the sprite grid (14x15 default) at scale 2/3/4/6; no sub-pixel blur (pixel-diff test at DPR 1 and 2).
3. 7 mascots mounted: exactly 6 animate and the 7th shows frame 0; unmounting one lets the 7th start within one tick.
4. A state change within 600 ms of the previous change is delayed until dwell elapsed; three state changes in 2 s tool_running collapse into one `tool_running` animation (unit test with fake clock).
5. With `prefers-reduced-motion: reduce` or `CENTO_REDUCE_MOTION=1` equivalent setting, all canvases show a static first frame and the `crash`, `glitch`, `panic` animations never autoplay.
6. Category chunk for `agent` <= 40 KB gzip; no animation JSON is fetched until a Mascot for that category mounts; per-frame draw <= 1 ms (benchmark of 6 simultaneous).
7. Canvas has `aria-hidden="true"` and the component renders no text; callers must pass state text separately (lint + test).
8. Pausing: hidden tab or element out of viewport stops the rAF loop (0 frames drawn in 1 s test).

## Guardrails (MUST / MUST NOT)
- MUST NOT drive or change product state; the component is a pure view of the `state` prop (DESIGN.md 11.4).
- MUST NOT autoplay `crash`, `glitch`, `panic` under reduced motion and MUST cap flashing to < 3 per second.
- MUST NOT render in payment, consent, security, destructive-confirm surfaces or assertive live regions (DESIGN.md 11.5).
- MUST only bundle JSON/SVG/sprite data from packages/mascot; GIFs (173 MB total) are never imported (DESIGN.md 19.7).

## Failure modes
- Animation chunk fails to load -> render static SVG first frame (or nothing), retry once, never throw.
- Canvas 2D context unavailable -> render the ASCII-style text fallback `(•_•)` with aria-hidden.
- Unknown colour -> violet.
## Notes
Spec reads the sprite from `palmap` per colour (palette chars from animations.json). Frame budget numbers come from DESIGN.md 19.6; TUI limits (2 ms redraw) belong to C033.
