# Questions

**Does Centcom see my Claude or Codex login?** No. It starts your own `claude` or `codex` and never reads their credential files.

**Can the relay read my messages?** No. See [Privacy and encryption](./privacy.md).

**Does it work offline?** Yes, alone or on a LAN.

**Is there an npm, Homebrew or Windows package?** Not yet; see [Install](./install.md).

**Do I need an account?** Only for hosted sessions ([Accounts and plans](./billing.md)).

**How do two people work on one project from two computers?** [Branch mode](./command-post.md).
