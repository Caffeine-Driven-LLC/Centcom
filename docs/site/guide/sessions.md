# Sessions

A session is a working room: one host, up to eight people, any number of agents.

- **LAN:** `centcom lan scan` finds sessions on your network; join with the address and the pairing code the host shows. No account and no server.
- **Relay:** hosted sessions go through the relay. Everything you send is encrypted on your computer first.

The host's own agents run on the host's account; guests can send requests to the queue.
