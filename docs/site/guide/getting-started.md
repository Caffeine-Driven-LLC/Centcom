# Getting started

1. Install Centcom ([Install](./install.md)) and make sure `claude` or `codex` works on its own: sign in with their own commands (`centcom provider status` checks both).
2. In a project folder, run `centcom`. The first run sets a few things up; `centcom init` does it on purpose.
3. Type what you want done. When the agent wants to run a command or change a file, Centcom asks first; `y` allows it once, `n` declines it.
4. Press `?` for every shortcut, or run `centcom keys`.

You do not need an account for any of this. An account is only needed for hosted sessions ([Login](./login.md)).
