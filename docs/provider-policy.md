# Who pays, and which provider methods are allowed (lane C105, CT-PROVIDER)

- **Who pays** (`computeWhoPays`): in branch mode the agent's owner pays; in a command post the host pays. `shared` is true when the payer did not type the prompt. `buildSpawnClearFields` gives the only two provider fields that go in the clear part of `agent.spawn`: `runs_on` and `provider`.
- **Start gate** (`evaluateStartGate`), run before an engine starts and before a guest prompt is claimed: method flag off -> `provider_method_disabled`; command post + subscription (or unknown) login + `provider.command_post.subscription` off -> `provider_policy_blocked`; flag on but the host has not confirmed -> `needs: host_confirmation`; everything else is allowed (API key and cloud logins always). A flag turning off never stops a running session.
- **Flags**: `provider.claude_code` (true), `provider.codex` (true), `provider.command_post.subscription` (false). Defaults apply until the flags client has loaded, so a subscription command post stays blocked offline.
- **Host confirmation** (`createHostConfirmation`): per session, in memory only, audited once as `provider.cp_subscription.confirmed {engine}`; a new session asks again. The notice text (`packages/tui/src/provider/messages.ts`) needs a human sign-off before release.
- **Guest spend** (`createGuestSpendControl`): counts guests and pauses/resumes them through the injected `setGuestsPaused` (the session lanes implement it with `control.policy`).
- **Local states**: `providerStateFor` maps provider error codes to `provider-auth-required`, `provider-cap-reached`, `provider-policy-blocked`. They drive the mascot and status line only and are never sent as `agent.state`.
- **Policy table**: `packages/agent/data/provider-policy.json` equals the reference rows in `contracts/fixtures/providers/policy-reference.json`; `node tools/refresh-provider-policy.mjs` refreshes `checked_at` each release (`--check` verifies the rows). `centcom provider status --policy` prints one line per method with its flag value now.
