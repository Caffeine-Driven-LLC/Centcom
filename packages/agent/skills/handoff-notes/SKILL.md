# Handoff notes

Use this when asked to hand work over, or when stopping before the task is finished.

1. State the goal in one sentence.
2. List what is done and what is verified, then what is left, in the order to do it.
3. Name the files that matter and the commands to run the checks.
4. Write down anything surprising: decisions made and why, things that looked wrong but are fine, open questions.
5. Say what you did not check. Keep it under one page and put it in a file the next person will find.
