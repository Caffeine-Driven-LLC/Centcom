# Transcript

- **Layout** (`TranscriptLayout`): each block's rows are cached by the item and the width, so streaming into the last message re-measures one block and scrolling builds only the rows on screen (10,000 blocks: a page in well under 16 ms). Items are replaced, never changed in place, so the item object is its revision. Above 5,000 blocks the oldest collapse into one `⋯ N earlier messages` row. `anchorAt` / `rowOf` keep the top visible block in place when the window is resized.
- **Scrolling**: `pageup` / `pagedown` move a screen minus two rows, `ctrl+home` / `ctrl+end` jump to the start or the end. While you are scrolled up the view stays still as messages arrive, and the bottom row says `↓ N new`; `ctrl+end` (or End, or `ctrl+l`) goes back to following the end.
- **Safety**: every string from an item (model text, tool commands and results, names) goes through `sanitizeForTerminal`: escape sequences, OSC commands (titles, hyperlinks) and control characters are removed, so nothing printed can clear the screen or change the terminal.
- **Shared sessions** (`reduceTranscript`): decrypted session events (`message.user`, `message.assistant.delta|done`, `message.system`, `tool.request|result`, `approval.request|decision`, `agent.exit`) become the same items. The relay's `seq` decides the order (an old `seq` is ignored); assistant deltas are put in index order with a buffer of 64, duplicates are dropped, and a gap older than 2 s is shown with `…`. Unknown kinds are ignored. Other members' messages show `▎`, their initial and name (`M · Maya`) in their colour: never colour alone.
- Rendering of blocks, Markdown and diffs is in `util/transcript.ts`, `util/markdown.ts`, `util/diff.ts`.
