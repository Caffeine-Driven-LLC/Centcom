# fleet sync (lane C062)

`new FleetSync(session, { clock, locks?, ring?, ids?, warn? })`, then `start()` / `stop()`: publishes our agents and file locks as session events and keeps a live view of everyone else's.

- **Publishing:** `spawn` (`agent.spawn`: ids and enums in the clear; label, branch, worktree and model encrypted; the relay's plan-limit refusal becomes `SpawnRejectedError`), `setState` (only names from the contract's state map that are meant for the wire; local-only ones such as `offline` give `LocalStateError`, unknown ones `UnknownStateError`; the same state twice sends once; at most 2 frames per agent per second, the latest wins), `exit`, `updateBranch` (`branch.update`, encrypted only), `reportConflict` (keyed path hashes in the clear, paths encrypted).
- **Locks:** `acquire(agentId, path, ttlMs?)` sends `file.lock` with the path's keyed hash (`pathHmac` of the current epoch, so another session gives another hash) and the path encrypted. `granted` when the relay sequenced it, `denied` when the relay answered with a denial (we stop waiting for that frame and never retry on our own). A server `expire` makes the local `LockBackend` release the lock. After a reconnect our locks are asked for again; a denial then means someone else took the path. `lockTransport()` is what the local lock client (lane C018) publishes through.
- **View** (`fleet()`): members with their agents (state, label, branch status, exit), the lock table (with its end time from the frame's own time and ttl), and conflicts. It is a pure reducer: replaying the same frames gives the same view and a repeated frame changes nothing. The sender, not an `owner` field, decides who owns an agent; events from non-members are ignored; an unknown state shows as the generic working state (`thinking`), with the original name kept; unknown lock actions are ignored. `deny` and `expire` count only from the server.
- **Events:** `changed`, `conflict` (only when one of my agents is involved; paths when readable), `lock-denied`, `lock-expired`.
- **Bus bridge:** `bridgeBus(bus, fleet, { mode, shareDetails? })` turns the local agent bus (`agent:started`, `agent:state_changed`, `agent:exited`, `worktree:created`) into the calls above; text that is only local is never forwarded.

The mock relay now arbitrates `file.lock` (first acquire wins, `deny` for others, `expire` after ttl) and can limit agents per member (`relay.maxParallelAgents`). Session client additions: `abandon(frameId)` and `pathMac(path)`.
